# FX 裁量売買支援ツール（MVP）

このリポジトリは、**自動売買ではなく裁量トレード向け**の意思決定支援ツールです。  
「エントリー判断」「リスク計算」「取引前チェック」を素早く行うことを目的にしています。

## コンセプト
- 売買執行は人間（裁量）
- ツールは以下を支援
  - テクニカル状況の可視化
  - RR（リスクリワード）計算
  - 許容損失ベースのロット計算
  - 取引前チェックリスト

## 3人のエージェントで決めた方針

### Agent 1: Macro Hawk（相場環境担当）
- 役割: いまが「トレンド相場」か「レンジ相場」かを見誤らない。
- 主張: 裁量ではエントリー精度よりも、**相場フェーズ認識**が先。
- 提案: SMA/EMA傾き、ATR、直近高安の位置を必ず表示。

### Agent 2: Risk Sentinel（資金管理担当）
- 役割: 1回の負けで口座を壊さない。
- 主張: 裁量でもルール化できるのは資金管理。
- 提案: 口座残高・許容リスク%・損切りpipsから、
  許容ロットを自動計算する機能を最優先。

### Agent 3: Execution Coach（執行品質担当）
- 役割: 感情トレードを減らす。
- 主張: 実行前チェックをUIに組み込めば、
  ルール逸脱を大幅に減らせる。
- 提案: 「指標前か」「損切り設定済みか」「シナリオが言語化されているか」を確認項目に。

### 合意（最終方針）
1. 完全自動売買はやらない（裁量支援に特化）
2. 最初のMVPは「チャート + 指標 + リスク計算 + チェックリスト」
3. 発注API連携は将来拡張（まずは判断品質と再現性を上げる）

## 機能（MVP）
- OHLCVデータ（CSV）読み込み
- EMA20 / EMA50 / RSI14 / ATR14 を計算
- 現在価格・トレンド簡易判定を表示
- RR計算（Entry / SL / TP）
- 許容リスクからのロット計算
- 取引前チェックリスト

## クイックスタート
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

起動後、サイドバーからCSVをアップロードしてください。  
想定カラム: `time,open,high,low,close,volume`
