# FX 裁量売買支援ツール（動作版MVP）

このリポジトリは、**自動売買ではなく裁量トレード向け**の意思決定支援ツールです。  
前回版の依存関係問題を解消し、**Python標準ライブラリのみ**で動作するCLI版にしました。

## 3人の凄腕エージェントで再設計した方針

### Agent 1: Macro Hawk（相場環境担当）
- 相場フェーズ（上昇/下降/レンジ）を先に判定。
- EMA20/EMA50と現在価格の位置関係で簡易判定。

### Agent 2: Risk Sentinel（資金管理担当）
- 口座残高・許容リスク%・損切り幅から、損失額と推奨ロットを計算。
- 裁量でも再現可能な資金管理を固定化。

### Agent 3: Execution Coach（執行品質担当）
- 感情トレード防止のため、実行前に数値で判断材料を確認。
- RSI/ATR/RRを毎回同じ手順で確認できるように統一。

## 機能
- OHLCV CSV読み込み（`time,open,high,low,close,volume`）
- EMA20 / EMA50 / RSI14 / ATR14 計算
- トレンド簡易判定
- RR計算（Entry / SL / TP）
- 許容リスクからの損失額・推奨ロット計算

## 使い方
```bash
python app.py --csv sample.csv --balance 300000 --risk-pct 1 --entry 156.20 --stop 155.95 --take 156.80
```

必須:
- `--csv`

任意:
- `--balance`（デフォルト: 300000）
- `--risk-pct`（デフォルト: 1.0）
- `--entry` / `--stop` / `--take`（未指定時は最新価格ベースで自動設定）

## CSV形式
- `time` は ISO8601推奨（例: `2026-01-01T00:00:00+00:00`）
- 必須カラム: `time,open,high,low,close,volume`
- 安定した指標計算のため、60本以上のデータを推奨（不足時はエラー）
